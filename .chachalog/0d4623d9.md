Show every piece of content a publication request covers, instead of only the first one.

A task raised by the publication workflow used to name a single item even when the request covered several, because that is all the task itself records. The card now lists all of them, with the type of each and a preview, and says how many there are. Long requests show the first few with a "Show all" that fetches the rest, and an item you are not allowed to open is counted rather than silently dropped.
